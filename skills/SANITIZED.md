# Что убрано и заменено в skills/

Копии пяти навыков (skill: папка с инструкцией SKILL.md, которую Claude Code и Codex подгружают по ситуации) сняты с рабочих навыков владельца комплекта и очищены. Проверка шла поиском по шаблонам: личные пути, имена, названия проектов, числовые идентификаторы Telegram (5 и более цифр), почты, IP-адреса, токены (`sk-`, `AKIA`, `число:AA...`), слова про место жительства и близких. Ниже перечислено каждое изменение. Файлы stop-slop (включая LICENSE и references/) скопированы без правок: поиск ничего личного не нашёл.
