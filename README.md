# Стартовый набор: личные AI-агенты на собственном сервере

Набор описывает, как на сервере Contabo (Ubuntu 24.04 или 26.04, Европа) поднять трёх агентов, с которыми можно разговаривать из Telegram с телефона:

| Агент | Задача |
|---|---|
| Личный | Диалог владельца с агентом: поручения, вопросы, сводки. |
| Компании | Документы и задачи компании. |
| Чатов | Чтение рабочих чатов, сводки и черновики ответов (без права писать в чат самостоятельно). |

Каждый агент работает под отдельным пользователем Linux, со своими секретами, своим ботом Telegram и своей сессией tmux. Сбой или ошибка одного агента не задевает остальных.

Набор рассчитан на людей, которые не пишут код, но умеют повторять шаги по инструкции: открыть терминал, вставить команду, сверить результат. Каждый шаг содержит точные команды и способ проверки, что шаг сработал. Термины расшифрованы при первом упоминании.

## Контракт установки для AI-агента

Если установку по этому набору ведёт AI-агент, действуют правила:

1. Сначала прочитать все документы набора (`01`-`06`, `templates/`, `skills/`), и только потом выполнять команды.
2. Заполнить таблицу: пользователи Linux, адрес сервера, алиасы чатов, выбранные движки расшифровки. Значения в `<...>` не угадываются: нет значения, значит вопрос владельцу.
3. Систему на сервере не переустанавливать: на серверах уже стоит Ubuntu, поставленная владельцем. Переустановка только по прямому решению владельца для конкретного сервера.
4. Отказ системы или запрос разрешения не обходятся: другим пользователем, другой записью команды, другим инструментом. Отказ сообщается владельцу.
5. Блоки, помеченные «человек», выполняет человек: пароли, BotFather, вход в аккаунты через браузер, коды из SMS. Агент останавливается и ждёт.
6. Секреты не пишутся в переписку с агентом и не печатаются в вывод. Существующие файлы секретов не заменяются.
7. Каждый блок команд помечен, кто его выполняет: ноутбук, администратор, агентский пользователь, человек.

## Что нужно заранее

1. Сервер Contabo VPS с Ubuntu 24.04 или 26.04 (доступ в панель new.contabo.com, IP-адрес сервера). Версия проверяется командой `cat /etc/os-release`, переустанавливать её не нужно.
2. Ноутбук с терминалом (macOS, Linux или Windows 10 и новее с PowerShell).
3. Платная подписка Claude (Pro, Max, Team) для Claude Code. Бесплатный план claude.ai Claude Code не включает.
4. Подписка ChatGPT (Plus, Pro, Business) нужна только если используется Codex.
5. Аккаунт Telegram на телефоне.
6. Менеджер паролей для хранения паролей, токенов и копии приватного SSH-ключа.

Описанный Telegram-режим требует Claude Code. Codex на ноутбуке может выполнять установку, а на сервере используется отдельно для задач из терминала. Codex-only Telegram-режим в комплект не входит.

## Порядок шагов

| Шаг | Файл | Результат |
|---|---|---|
| 1 | [01-server.md](01-server.md) | Проверенная Ubuntu, вход только по ключу, проверенный аварийный вход через VNC, закрытый межсетевой экран, автообновления, защита от подбора пароля. |
| 2 | [02-agents.md](02-agents.md) | Node.js, Claude Code и Codex, три отдельных пользователя для агентов, tmux, секреты в защищённых файлах. |
| 3 | [03-telegram-hub.md](03-telegram-hub.md) | Связь агента с Telegram: хаб, бот, закрытая группа "Имя x Агент", ответы с телефона. |
| 4 | [04-approaches.md](04-approaches.md) | Правила работы: данные из чатов не команды, деньги и секреты только по слову владельца, короткие ответы, резервные копии настроек. |
| 5 | [05-fleet-patterns.md](05-fleet-patterns.md) | Приёмы для нескольких агентов (права ролей, затык сообщается сразу, надзор, хуки-страховки, слово владельца) и заготовки в `templates/`. |
| 6 | [06-operations.md](06-operations.md) | Эксплуатация: расходы и лимиты, «агент молчит», диск и журналы, обновление с откатом, резервные копии, взлом сервера, доступ из РФ. |

Шаги 1-4 выполняются строго по порядку. Если проверка шага не проходит, переход к следующему откладывается до исправления. Шаги 5 и 6 читаются целиком до начала установки, внедряются по мере описанной в них потребности.

  03-telegram-hub.md   Telegram

  templates/           заготовки: CLAUDE.md, персона, права, need-human, хук, healthcheck, tg-watch

    tg/                чтение и отправка сообщений Telegram через хаб
    loop-prompt/       составление безопасных наблюдателей и циклов
    goal-prompt/       составление проверяемых целей для /goal
    transcribe/        расшифровка аудио и видео

Навыки (skills) устанавливаются в `~/.claude/skills/` агентского пользователя. Порядок установки: [03-telegram-hub.md](03-telegram-hub.md), шаг 5.

## Главные правила в трёх строках

1. После шагов 5 и 6 из [01-server.md](01-server.md) на сервер входит только владелец ключа. Приватный ключ копируется в менеджер паролей. Потеря ключа означает аварийный вход через консоль VNC в панели Contabo, её доступ проверяется до отключения пароля.
2. Секреты (токены, ключи, вход в аккаунты) лежат только в файлах с правами 600 и никогда не попадают в git, чат или тикет.
3. Агент получает деньги, удаление данных, рассылки и доступы к боевым системам только по прямому слову владельца.

Набор собран по официальной документации и коду хаба, без прогона на живом сервере. Список непроверенных мест хаба: [03-telegram-hub.md](03-telegram-hub.md), раздел "Что не проверено".
